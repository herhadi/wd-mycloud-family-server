# Recovery

Recovery documentation is organized into two paths:

1. **Bricked existing disk** — restore the known-good Gen1 layout without repartitioning unless necessary.
2. **Clean Debian Jessie from zero** — rebuild the root/boot images on a correctly partitioned Gen1 disk.

See [`install-jessie.md`](install-jessie.md) for the complete procedure and troubleshooting notes collected from the project's actual recovery.
